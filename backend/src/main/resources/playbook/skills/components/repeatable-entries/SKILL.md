# 可重复条目（添加 / 新增一段经历）

本 skill 是陈述句的经验，不是命令。每一条都要按当前页面核对；页面和经验不一致时，以页面为准。

## 长什么样

- 项目经历、实习经历、工作经历、教育经历、获奖、作品、语言能力这类区域，每一段是一张卡片（一组字段）。区域里一开始常常只有一张空卡片，或者只有一个「添加」「新增」「+」「+ 添加项目经历」「Add another」按钮。
- 添加按钮的位置因站点而异：区域底部、区域标题右边、卡片下方的虚线框、卡片右上角的「+」。全页可能有好几个「添加」，要限定在对应区域里找，不按全页的第几个去猜。
- 飞书 / Lark 一类招聘系统（以及不少自建表单）里，一张卡片常常是「编辑态」：卡片里有「保存」「确定」「完成」「取消」按钮。当前卡片没保存之前，点区域的「添加」可能没有任何反应，或者添加按钮是灰的（disabled）。
- 有的站点要先把当前卡片的必填项填完，添加按钮才可用；有的站点保存后卡片会收起成一行摘要（名称 + 时间 + 编辑 / 删除）。

## 顺序

1. 先数简历（read_resume 的原文）里这一类经历有几段，记进计划，例如「项目经历：简历 3 段，页面 0 张」。
2. 填当前这张卡片。填完后看卡片里有没有「保存」「确定」「完成」：有就先按它，再看快照，确认卡片收起成摘要或者出现保存成功的提示、没有红字错误。
3. 再点这个区域的添加按钮。**点完一定要看新快照，确认真的多出一张空卡片**（同名字段多了一组、摘要列表下面出现了新的编辑框）。工具结果写「完成」只表示点击发出去了，不表示条目加上了。
4. 新卡片里填下一段，重复 2、3。
5. 都填完后数一遍这个区域的卡片（或摘要行），和简历的段数对上；对不上就找出少的是哪一段。

## 点了添加却没有多出卡片

按这个顺序排查，每一步都看快照：

- 当前卡片还没保存：卡片里有「保存」「确定」「完成」就先按；按完再点添加。
- 当前卡片的必填项没填完：读卡片附近的红字或星号，补上再保存。
- 点错了按钮：同一个区域里可能有好几个「添加」（添加技能标签、添加附件、添加描述行）。找区域底部或标题旁边写着这个区域名字的那个（「添加项目经历」「+ 新增项目」）。
- 按钮是灰的（disabled）或在可视区域外：滚动到区域底部再看，读按钮附近的说明。
- 新卡片其实加上了，只是出现在区域顶部、或者把旧卡片收起了：看整个区域，不只看按钮附近。
- 换一种点法：点按钮的文字、点按钮旁边的「+」图标。

## 不要编原因

- 不要说「这个组件需要真实用户触发」「前端不允许自动化」一类的话：这类说法几乎都是没排查到真正原因（多半是没保存、点错了按钮、必填没填）。
- 排查完仍然加不上时，用 ask_user 说清楚：哪个区域、点的是哪个按钮（名字和位置）、点了几次、每次快照里看到了什么（有没有新卡片、有没有红字、按钮是不是灰的），请用户点一次或者告诉你该点哪里。用户加出空卡片后，你接着填。
- 卡片里的按钮叫「确定」「完成」时，系统按提交类按钮拒绝，你点不了：用 ask_user 请用户点一下这张卡片里的这个按钮（说清是哪个区域的哪一张），回复后接着添加下一段。卡片里叫「保存」的你可以自己点。

## 链接字段

- 项目链接、作品集链接、GitHub、个人主页、论文链接这类字段，从 read_resume 原文开头的「文件里的超链接」里取：简历里挂在项目名或「链接」字样上的超链接，网址列在那里，按链接文字对应到是哪一个项目。
- 正文里直接写出来的网址也可以用。简历里没有链接的就留空（选填）或问用户（必填）；不编网址，不拿岗位页、公司官网的链接去凑。
