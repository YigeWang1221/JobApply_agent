# 级联与分组城市

## 先用 browser_select_option

- 级联一次调用：values 每层写一个，从上到下，例如 `["广东", "深圳"]`、`["浙江省", "杭州市", "西湖区"]`。系统打开后一层一层找、点，等下一列出来再找下一层，最后读回框里显示的值。
- 只要选到某一级（例如只选到省）就只写到那一级。
- 某一层没找到时系统不再往下点，返回「第几层没找到」和这一层能看到的选项原文：从里面挑原文再调一次（前面几层照旧写）。
- 「点完第 N 层列表就关了」：这个控件只有 N 层，或者点中的是可选的上一级。看新快照里框里显示的是什么。
- 带搜索框的级联可以加 `search: true`：系统先输入第一层的值。搜索结果常带完整路径（「广东 / 深圳」），同名城市要看路径区分。

## 分组城市和多选

- 分组城市：一个大的弹层，上面是热门城市或分组标签（华东、华南、海外等），下面是城市列表。点分组标签只是切换，没有选中；系统按选项原文找，找不到时会把看得到的列出来，必要时先手动点分组再选。
- 多选的城市字段，选中后显示成一组标签（tag）。以「已选标签」核对：输入框是空的不代表没选；输入框里还留着搜索文字也不代表选上了。
- 意向城市、调剂城市的排序和数量属于这一次申请的选择，资料里没有时问用户，不自行排序或补齐。
- 有上限的多选达到上限后，再点其它城市可能没有反应或替换掉旧的；以标签区的最终结果为准。

## 经验

- 城市的写法以选项为准：「上海」「上海市」或英文名，语义一致即可。
- 有的级联允许选中非叶子节点（选「整个省」），有的不允许。看框里实际显示的是什么，再判断选中的是哪一级。
- 弹层可能挡住下面的字段。选完之后弹层没关时按一次 Escape 或点一下空白处，不反复按。
- 选完之后字段旁边仍有必填错误时，聚焦后按 Tab 触发失焦校验。
