# 分组城市与级联选择

## 长什么样

- 级联选择（cascader）：点开后是几列，左边一列是上一级（省、地区、国家），右边是下一级（城市）。快照里常表现为一个 combobox 或 textbox，点开后出现 menu / listbox，每一项是 menuitem 或 option。
- 分组城市：一个大的弹层，上面是热门城市或分组标签（华东、华南、海外等），下面是城市列表；也可能是「省 → 市」两级的列表。
- 多选的城市字段，选中后通常显示成一组标签（tag），每个标签带一个关闭的小叉。

## 经验

- 点击分组标题或上一级的名字（例如某个省、某个地区）往往只是展开下一级，并没有选中任何城市。要再点组内的具体城市，然后看是否出现了已选标签或输入框里的值。
- 有的级联允许选中非叶子节点（选「整个省」），有的不允许。看点击后输入框或标签里实际显示的是什么，再判断选中的是哪一级。
- 多选城市以「已选标签」核对：输入框是空的不代表没选，标签区里有才算选上了。反过来，输入框里还留着搜索文字，也不代表选上了。
- 级联里常有搜索框。输入城市名后出现的结果可能带完整路径（「省 / 市」），选和资料一致的那一条；同名城市要看路径区分。
- 城市的写法以选项为准：选项可能是「上海」「上海市」或英文名。语义一致即可，不需要逐字相同。
- 意向城市、调剂城市的排序和数量属于这一次申请的选择，资料里没有时问用户，不自行排序或补齐。
- 有上限的多选（例如最多选 3 个）达到上限后，再点其它城市可能没有反应或替换掉旧的；以标签区的最终结果为准。
- 弹层可能挡住下面的字段。选完之后弹层不一定自动关闭；按 Escape 或点弹层外的空白处一般能关掉，关掉后再读一次快照核对。
- 选完之后字段旁边仍有必填错误时，聚焦后按 Tab 触发失焦校验，然后再看错误是否消失。
