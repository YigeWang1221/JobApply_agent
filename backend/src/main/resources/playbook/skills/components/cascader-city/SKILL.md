# 级联与分组城市

## 扁平资料补全上级路径

- 资料里常只写叶子值（例如籍贯/所在地只写「台州」、学校所在地写「杭州」、专业写「软件工程」），而表单的级联往往从省或国家开始（「省 → 市」「国家 → 省 → 市」「学科门类 → 专业类 → 专业」）。
- **客观的上下级归属由你自己按常识补全**，不要因为资料只写了「台州」就去问用户属于哪个省或国家：
  - 一开始就知道是省市级联时，直接传 `["浙江", "台州"]`（或 `["浙江省", "台州市"]`）；国家省市级联直接传 `["中国", "浙江", "台州"]`。
  - 如果一开始只传了 `["台州"]`，工具返回「第 1 层没找到」并列出第 1 层的选项原文（例如全是省份 `["北京市", "浙江省", ...]` 或国家 `["中国", "海外", ...]`），直接从返回的选项原文里挑出「台州」所属的上级拼成完整数组（如 `["中国", "浙江省", "台州市"]`）再调一次，**不要去问用户**。

## 先用 browser_select_option

- 级联一次调用：`values` 每层写一个，从上到下，例如 `["广东", "深圳"]`、`["浙江省", "杭州市", "西湖区"]`。系统打开后一层一层找（长列表和虚拟滚动列表会自动滚动/滚轮查找）、点中，等下一列出来再找下一层，最后读回框里显示的值。
- 只要选到某一级（例如只选到市）就只写到那一级。
- 「点完第 N 层列表就关了」：说明这个控件只有 N 层，或者点中的本身就是叶子节点。看新快照里框里显示的是什么。
- 带搜索框的级联可以加 `search: true`：系统先输入第一层的值。搜索结果常带完整路径（「广东 / 深圳」），同名城市要看路径区分。

## 选不中或「还有下一列」时

- **某一层没找到**：系统不再往下点，返回「第几层没找到」和这一层能看到的选项原文。从返回的选项里挑语义一致或客观归属的原文，把前面几层照旧带上再调一次。
- **选了一半、右边还展开了下一列**（或返回 `need_more_levels` / 面板还开着显示下一级选项）：
  - 若下一列是资料里能确定的层级（如前两层选了「中国 → 浙江」，下一列是城市列表），把下一层的原文补进 `values` 再调一次，或者直接在最新快照（弹出层视图）里用 `browser_click` 点下一列对应的选项；
  - 若下一列是资料和简历里都没有的**更细层级**（例如已经选到「浙江省 / 台州市」，第 3 列要求必选具体区县「椒江区 / 黄岩区 / 路桥区…」），不要自己瞎猜，把返回的这一列选项原文用 `ask_user` 列给用户选。

## 分组城市和多选

- 分组城市：一个大的弹层，上面是热门城市或分组标签（华东、华南、ABCD 字母分组、海外等），下面是城市列表。点分组标签只是切换面板，没有选中城市；如果直接找没看到目标城市，可以在弹出层快照里先点对应的分组标签（如「华东」或「GHIJ」），再点里面的城市。
- 多选的城市字段，选中后显示成一组标签（tag）。以「已选标签」核对：输入框是空的不代表没选；输入框里还留着搜索文字也不代表选上了。
- **主观意愿问用户**：意向城市、调剂城市的取舍、排序和数量属于用户的主观意愿，资料里没有时用 `ask_user` 问用户，不自行排序或补齐。
- 有上限的多选达到上限后，再点其它城市可能没有反应或替换掉旧的；以标签区的最终结果为准。

## 经验

- 城市和省区的写法以选项原文为准：「上海」与「上海市」、「浙江」与「浙江省」或英文名，语义一致即可。
- 弹层可能挡住下面的字段。已经选好但弹层没关时按一次 Escape 或点一下空白处，不反复按。
- 选完之后字段旁边仍有必填错误时，聚焦后按 Tab 触发失焦校验。
