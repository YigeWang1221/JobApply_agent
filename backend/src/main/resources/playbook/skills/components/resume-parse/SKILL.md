# 简历解析之后的校正

## 发生了什么

- 很多申请系统在上传主简历后自动解析，把识别出的内容回填到表单：联系方式、教育经历、工作经历、项目、技能。
- 回填会覆盖已经填好的字段，也可能新增整段经历。所以顺序是：先上传简历 → 等解析结束（「解析中」「Parsing」消失，或页面提示解析完成）→ 再读一次快照 → 再校正字段。
- 解析结束的信号因站点而异：提示条、弹窗（「是否用解析结果填充」）、字段突然有了值。弹窗里的选择（覆盖 / 不覆盖）要看说明文字；拿不准时问用户。

## 常见的解析错误

- 学校：同名或名称相近的学校被识别成另一所（例如识别成另一个城市或另一个国家的同名学校），学校所在城市识别错。
- 联系方式：国际区号识别错，或者区号和号码被拆错。
- 日期：开始或结束日期偏移一天或一个月，年月顺序颠倒，「至今」没有识别。
- 经历：某一段项目或工作经历整段遗漏；两段经历被合成一段；描述被截断。
- 学位：旧版的学位名称或简历里的其它写法被带进来，和资料里的写法不一致。
- 语言：中文简历的字段被填进英文表单（或反过来），需要按表单的语言取资料里对应语言的写法。

## 经验

- 解析出错的原因通常查不清。校正时只把字段改成资料里的值，不在资料之外推算（例如不自行加减日期去「抵消」偏移）。
- 逐段核对：解析新增的每一段经历都要和资料对照；资料里没有的段落，问用户是否删除，不自行删。
- 有「同步更新在线简历」「用解析结果更新我的资料」一类的选项时，它可能让以后的解析继续覆盖人工整理的内容。是否关闭由用户决定；关闭后要回读勾选状态。
- 校正完保存，再回读一次：有的站点在保存或翻页时会再解析一次，把校正过的字段改回去。
- 解析自动填进来、你没有动过的字段也要核对（例如「所在地点」「期望城市」可能是从简历里猜的）。核对过的字段在报告总结里写明「页面自动解析」，和资料 / 简历不一致的改掉或问用户。
- 解析常常漏掉项目、实习的条目或只填一部分：对照简历原文逐条补全。
- 解析结果和资料不一致、又判断不了哪个对时，保留资料的值，并把不一致之处写进报告，交给用户核对。
