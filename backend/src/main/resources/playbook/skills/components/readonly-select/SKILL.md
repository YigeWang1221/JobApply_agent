# 下拉框

## 先用 browser_select_option

- 任何下拉都先用它，一次调用：target 写点开它的那个框（combobox、只读的 textbox、按钮或没有角色的框都行），values 写要选的项。
- 系统做的：原生 select 按选项原文直接选；自定义下拉真实点击打开 → 等列表出来 → 列表长就滚动着找 → 找到就点 → 读回框里显示的值是不是对得上 → 列表还开着就按一次 Escape。
- 能输入的下拉在列表里找不到时，系统会把值输进框里过滤一次。学校、专业、城市这类远程搜索的，加 `search: true`，系统先输入再等结果。
- 匹配顺序：完全相同 → 忽略空格、全角半角、大小写后相同 → 唯一一个包含它的（写「硕士」能选到「硕士研究生」）。有几项都对得上、或者一项都没有时，系统不点，返回这一层能看到的选项原文。

## 选不中时

- 从返回的选项原文里挑和资料语义一致的那一项，原样写进 values 再调一次。
- 写法不同但意思一样的可以选（「本科」和「大学本科」）；意思只是相近的不硬选（「硕士」和「博士」、不同城市的同名学校），没有一致的就用 ask_user 问用户，把选项原文给用户看。
- 有「其他」选项并带补充输入框时，先选「其他」，再在新出现的输入框里填。
- 返回说「还有更多没列出」：写得更完整再选，或者带 search: true。
- 实在选不上再手动：点开框，在新快照里找到选项点它。

## 没有名字的下拉

- 快照里常是 `combobox ""`（没有名字）。按它前面最近的标签文字、所在的区域（基本信息、教育经历第 2 段）认是哪个字段，不按出现顺序猜。

## 经验

- 键入文字只是过滤，没有选中；要点了列表里的项、框里显示了选中项才算。只留下键入的文字，保存时往往会被清空。回车不可用，联想框靠点选项提交。
- 对只读下拉键入没有效果（键入之前系统会告诉你「这是只读的显示框」）；对原生 select 也不要键入，用 browser_select_option。
- 学校、专业这类远程搜索的结果里可能有同名或相近的条目，要按完整名称和所在地核对，不选第一个相近的。
- 下拉框已经显示选中值，但字段旁边仍有必填错误时，聚焦后按 Tab 触发失焦校验。
- 多选下拉以已选标签核对：输入框是空的不代表没选。
- 一个下拉的选择可能改变后面的字段（选了国家才出现省份，选了「其他」才出现补充输入框）。后面的字段要在新快照里找。
