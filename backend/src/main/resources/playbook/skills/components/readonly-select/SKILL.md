# 只读下拉框与可搜索下拉框

## 长什么样

- 原生 select：快照里是 combobox，选项直接在下面，用选项操作（select_option 一类）就能选。
- 组件库的只读下拉：快照里可能是 combobox 或 textbox，但不能输入；点开后出现 listbox，选项是 option。
- 可搜索的下拉：输入框可以键入，键入后列表按关键字过滤，再从列表里点选。
- 远程搜索：键入后要等列表从服务器加载出来，加载中可能显示「加载中」「Loading」或空列表。

## 经验

- role=combobox 不一定能键入。先看它是原生 select、只读下拉还是可搜索的输入框，再决定用选项操作还是先输入再点选。对只读下拉键入没有效果，对搜索框用选项操作也会失败。
- 可搜索下拉里，键入文字只是过滤，并没有选中；要在列表里点一项，看输入框显示的值变成了选中项才算。只留下键入的文字、没有点选，保存时往往会被清空。
- 选项的写法以页面为准：资料里写的和选项不一致时，选语义一致的那一项；有「其他」选项并带一个补充输入框时，通常是先选「其他」再填输入框。没有语义一致的选项时，问用户。
- 选项很多的列表（国家、学校、专业）常常是虚拟滚动：快照里只有可见的一部分。用搜索过滤比滚动找更可靠。
- 学校、专业这类远程搜索的结果里可能有同名或相近的条目（同名的学校在不同城市或不同国家）。要按完整名称和所在地核对，不选第一个相近的。
- 下拉框已经显示选中值，但字段旁边仍有必填错误时，聚焦后按 Tab 触发失焦校验。
- 多选下拉以已选标签核对，和城市多选一样：输入框是空的不代表没选。
- 一个下拉的选择可能改变后面的字段（例如选了国家才出现省份，选了「其他」才出现补充输入框）。选完之后系统会重新取快照，后面的字段要在新快照里找。
