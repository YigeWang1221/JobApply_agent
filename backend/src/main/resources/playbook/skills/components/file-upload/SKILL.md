# 文件上传

## 流程

- 页面上的上传位置常写作「上传简历」「上传附件」「Upload」「Attach」「Choose file」，也可能是一块拖放区域。这些按钮名字不碰提交类词，可以直接点。
- 点上传按钮后，浏览器会打开一个文件选择窗口（file chooser）。窗口打开之后，才能用上传文件的工具把文件交给它。没有打开窗口就上传，工具通常会报没有可用的文件选择窗口。
- 上传的文件是系统准备好的等字节副本（放在允许上传的目录里，和原件的哈希一致）。原件的内容和排版不修改，也不转换格式。
- 用哪个文件由用户选：页面上有上传位置时，先请用户选文件，模型只看到文件编号和文件名。

## 经验

- 选中文件只代表文件交给了页面，不代表上传完成。要等「上传中」「Uploading」、进度条或转圈消失，再看附件列表里有没有这份文件。
- 回读每份附件：文件名、大小（如果显示）、完成状态，以及有没有「上传失败」「格式不支持」「文件过大」一类的提示。
- 有的附件栏一条只能挂一个文件：多份文件（作品集、成绩单、证书）要先点「添加」新增条目，再逐个上传、逐个核对。
- 同一个页面可能有好几个上传位置（简历、作品集、其他附件），按区域标题区分，不按出现顺序猜。
- 上传简历往往会触发解析，解析会回填并覆盖已填的字段。见 resume-parse。所以有解析的上传位置，应当先上传、等解析结束，再填其它字段。
- 一次打开了多个文件选择窗口时，要逐个确认每个窗口对应哪个上传位置，不盲目批量取消。
- 刷新或翻页后附件可能丢失；保存后回读时要连附件一起看。
- 文件格式和大小限制通常写在上传位置旁边（例如只收 PDF、不超过 10MB）。不符合时告诉用户，不自行转换或压缩文件。
- 替换已上传的文件时，先删掉旧的条目（小叉或「删除」按钮），再上传新的；删掉之后再读一次快照，确认旧文件确实不在了。
