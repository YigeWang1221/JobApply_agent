# 日期与年月选择

## 长什么样

- 输入框形式：一个 textbox，占位文字是格式提示（YYYY-MM、YYYY/MM/DD、MM/YYYY 等），点开后弹出日历面板。
- 面板形式：年、月、日分层选择；年月选择器常先显示年份列表，选了年份再显示月份。
- 范围形式：一个控件里有开始和结束两个输入框（开始时间 ~ 结束时间），或者两个独立的控件。
- 原生控件：input type=date / month，快照里可能直接是一个 textbox。

## 经验

- 直接往日期输入框里键入，可能被控件忽略、被改成另一种格式，或者写进了相邻的字段（尤其是范围控件，开始和结束共用一个弹层）。键入之后要看输入框里实际显示的值。
- 键入不生效时，用日历面板选：先切到目标年份，再选月份，再选日期。面板上的年份翻页按钮名字常是「上一年」「下一年」或箭头，不碰提交类词。
- 有的控件只接受面板选择，输入框是只读的；这种情况下键入不会有任何效果。
- 年月控件里只选到月份就够了，不需要日期。资料里只有年月时，不要自己补一个日。
- 「至今」「Present」通常是一个单独的复选框或面板上的按钮，勾上后结束时间会变成不可填。资料里写的是在读或在职时才用它。
- 日期以资料为准，不能自行加减一天或一个月。页面显示的值和资料不一致时，先看是不是格式差异（例如 2025-09 和 09/2025），再看是不是控件按时区或月份边界做了偏移。
- 填完之后聚焦再按 Tab 触发失焦校验；有的控件只有失焦后才把值写进表单。
- 保存后回读：重新进入这一步或刷新，看值还在不在，格式对不对。
