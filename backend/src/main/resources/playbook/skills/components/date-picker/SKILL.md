# 日期与年月选择

## 先用 browser_set_date（四种常见形态）

- 一个日期一次调用：`target` 写日期框（快照里的 textbox / combobox，没有名字时按前面的标签文字认），`date` 写 `YYYY-MM-DD`；字段只要年月就写 `YYYY-MM`，只要年份写 `YYYY`。不要自己补一个日：资料只有年月、框却要到日时，系统会返回 `need_day`（见下面）。
- 系统会自动识别四种日期控件形态并处理，结果里写明是怎么设的、读回的值对不对得上：
  1. **原生控件**（`input type=date / month`）：直接设 ISO 格式的值。
  2. **可键入的框**：按占位符或现有值的格式（`YYYY-MM`、`YYYY/MM/DD`、`MM/YYYY` 等）键入，再按 Tab 失焦，读回显示的值。
  3. **只读的日历网格面板**（点开出日期表 / 月份表 / 年份表，如 Ant Design、Element UI、react-datepicker）：面板里有输入框就先在里面键入；面板头部有年份/月份原生 `<select>` 下拉就直接选；否则点面板头部的年份 / 月份切到年份表、月份表跳到目标年月，或当头部不可点时用左右翻页箭头连续翻到目标年月，最后点日期格。
  4. **滚轮式多列面板**（年、月、日分为并排的上下滚动列，常见于移动端风格或自建校招表单）：系统在对应列上滚动/滚轮定位到目标年、月、日并依次点击。
- 范围控件（开始 ~ 结束）：如果是两个独立的输入框，开始、结束各调一次 `browser_set_date`；如果是点开同一个框在面板上连点两个日期，先试 `browser_set_date`，不行就点开面板后在快照里分步点开始和结束。

## 结果怎么处理与分步回退

- **「读回的值对不上」**：看新快照里这个框显示的是什么。常见是格式差异（`2025-09` 和 `09/2025`）；真的不对时再调一次，或者在面板快照里分步点。
- **「面板上还有『确定』」**（`needs_confirm`）：有的日历或滚轮面板点完年月日后要按「确定 / 确认 / OK」才写回输入框。系统的脚本不点按钮，由你在新快照里找到面板上的「确定」，用 `browser_click` 点它（`purpose: confirm`，`final_step_suspected: false`），再看新快照核对。
- **「need_day」**：这个框要精确到日，你给的只有年月。系统已把面板翻到过那一年那一月、没有点任何日期，并按 Escape 把面板关上（原生 date 框没有动）。不要自己编一个日：把这一页所有缺日的日期攒起来，用一次 `ask_user` 问用户各是哪一天；用户回答后用 `browser_set_date` 写完整的 `YYYY-MM-DD` 再设一次。
- **「没找到」或面板结构特殊**：结果会返回面板现在的样子（表类型、头部文字、可见的年份/月份/日期格或列项）。照返回的内容或弹出层快照用 `browser_click` 分步操作：
  - 日历网格：点头部的年份文字切到年份表（不在当前十年就点十年翻页箭头）→ 点年份 → 点月份 → 点日期；如果头部年份文字点不动，直接点上一页/下一页箭头翻过去。
  - 滚轮多列：在弹出层快照里找到年列、月列、日列对应的项依次点击，最后点面板上的「确定」。
- **「这是只读的显示框」**（键入前系统检查出来的）：不要再用 `browser_type` / `browser_fill_form` 往里键入，改用 `browser_set_date`。
- 面板关不掉时按一次 Escape 或点一下空白处就够，不反复按 Escape。

## 经验

- 「至今」「Present」通常是一个单独的复选框或面板上的按钮，勾上后结束时间会变成不可填。资料里写的是在读或在职时才用它。
- 日期以资料为准，不能自行加减一天或一个月。页面显示的值和资料不一致时，先看是不是格式差异，再看是不是控件按时区或月份边界做了偏移。
- 有的控件只有失焦后才把值写进表单；`browser_set_date` 键入后已经按过 Tab。字段旁边仍有必填错误时，聚焦后再按一次 Tab。
- 保存后回读：重新进入这一步或刷新，看值还在不在，格式对不对。
