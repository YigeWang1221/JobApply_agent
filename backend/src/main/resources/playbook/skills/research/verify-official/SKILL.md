# 官网核验

## 目的

候选池里撒网搜到的岗位标着「未核验」。核验就是到公司自己的招聘站上确认：

1. 这个岗位现在还在招吗；
2. 官方岗位链接是什么（以后申请从这个链接进）；
3. 要求（城市、届别、学历、方向）和之前读到的有没有变化。

## 找到官方招聘站

- 常见形式：`campus.<公司域名>`、`jobs.<公司域名>`、`<公司域名>/careers`，或者「公司名 + 校园招聘」搜到的官方页面。
- 第三方聚合站不算官方。拿不准是不是官方站时，看页面底部的公司信息和备案。

## 在站内查

- 国内校招站多是单页应用：用 browser_navigate 在自己的调研标签页打开，用快照读列表。
- 先找搜索框：用 browser_type 输入岗位关键词（不要按回车），再点旁边的「搜索」按钮；没有搜索框就用筛选项（城市、岗位类别、校招 / 实习）。
- 列表很长时用「下一页」或页码翻页；用 browser_find 找岗位名比整页读更快。
- 打开详情（点岗位名或详情链接），读岗位名、城市、要求、发布时间。
- **只读**：不点「立即申请」「投递」「收藏」，不填任何表单。系统也会拒绝申请类按钮。

## 需要登录时

有的站点不登录看不到岗位列表或详情。用 ask_user 请用户在 Chrome 里登录这个站（说清楚是哪个网址），登录好后回复；你不替用户登录。

## 记结果

- 找到了：update_lead 写 `verified: verified`、`official_url`（详情页的地址），要求有变化时在 note 里写明。
- 找不到：确认搜过岗位名和相近的叫法、翻过列表后，写 `verified: not_found`，note 写查过哪里、怎么查的。
- 最后告诉用户核验了几个、哪些找到了、哪些没找到。
